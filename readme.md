# 🏠 Forecasting the Cost of Housing

> **Прогнозирование стоимости жилья с использованием машинного обучения**

Этот проект направлен на построение модели машинного обучения для прогнозирования рыночной стоимости жилья на основе исторических данных. Решение может быть полезно как для покупателей и продавцов недвижимости, так и для аналитиков и агентств.

## 📖 Описание проекта

Проект решает задачу регрессии: предсказание цены на жильё на основе таких признаков, как площадь, количество комнат, местоположение, год постройки и др.  
Используются реальные или синтетические данные (в зависимости от источника), которые проходят полный цикл обработки: от очистки и визуализации до обучения и оценки моделей.

Основная цель — создать точную, интерпретируемую и воспроизводимую модель, которую можно использовать в реальных условиях.

---

## ⚙️ Функциональные возможности

- Загрузка и предварительная обработка данных
- Визуальный анализ распределений и корреляций
- Инженерия признаков (feature engineering)
- Обучение нескольких моделей машинного обучения:
  - Линейная регрессия
  - Случайный лес
  - Градиентный бустинг (XGBoost / CatBoost)
- Оценка качества моделей (MAE, RMSE, R²)
- Сохранение лучшей модели и возможность предсказания новых значений

## 🛠 Технологический стек

- **Язык программирования**: Python 3.x

- **Инструменты**: Jupyter Notebook (опционально), VS Code / PyCharm

## 🚀 Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/CheshirSml/forecasting_the_cost_of_housing.git
   cd forecasting_the_cost_of_housing
   ```

2. **Создайте виртуальное окружение** (рекомендуется):
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   # или
   venv\Scripts\activate     # Windows
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите обучение модели**:
   ```bash
   python train_model.py
   ```

5. **(Опционально)** Запустите Jupyter Notebook для интерактивного анализа:
   ```bash
   jupyter notebook
   ```
